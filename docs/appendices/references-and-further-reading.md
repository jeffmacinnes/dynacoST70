# References and further reading

*To be expanded over time.* Currently a placeholder for:

- **Original Dynaco documentation** — the kit manual, the assembly diagrams, the schematic.
- **Pacific Transformer documentation** — PA-060 and A-470 spec sheets.
- **DynakitParts** — the current source for ST-70 kits and parts.
- **Audiokarma ST-70 thread** — the long-running community thread on building and modifying the ST-70.
- **The "VTA Mods"** — Roy Mottram / Tubes4HiFi documentation of the VTA-style driver board upgrade and other Dynaco mods.
- **Aspen Pittman, *The Tube Amp Book*** — a useful reference on tube fundamentals.
- **Morgan Jones, *Valve Amplifiers*** — the heavier engineering reference, useful for deeper theory.
- **EL34 datasheets** — multiple manufacturers (Mullard, GE, Sylvania, EH).
- **5AR4 / GZ34 datasheets** — same.
- **6GH8A datasheet** — RCA, GE.
