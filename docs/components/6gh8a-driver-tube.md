# 6GH8A driver tube

The 6GH8A is a compactron-era combined pentode/triode tube. In the ST-70's PC-3A driver board variant, two 6GH8As (V4 and V5) provide voltage amplification and phase splitting for the [EL34 output stage](el34-output-tube.md).

This build uses 6GH8A tubes with an adapter set from Amplified Parts (the tube has a 9-pin compactron base; the PC-3A board uses a slightly different socket).
