# First power-on

*Page to be written.* Planned coverage:

- The [variac](../test-equipment/variac.md) procedure: 0 → 25 → 50 → 75 → 100 → full voltage in stages.
- At each stage: visually inspect, check for smoke/smells, measure key voltages, listen for unusual noises.
- The "no tubes installed" first pass: confirms basic transformer operation without risking the tubes.
- The "rectifier installed, no output tubes" pass: confirms the rectifier and filter network without loading the supply.
- The "rectifier + bias pots set to maximum negative" full-tube pass: starts safe and dials in from there.
- What to do if anything is wrong: immediate power-off, [discharge filter caps](../test-equipment/high-voltage-safety.md#discharging-filter-caps), troubleshoot.
