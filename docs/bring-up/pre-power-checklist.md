# Pre-power checklist

*Page to be written after the build is complete and we go through bring-up in practice.* Planned coverage:

- Visual inspection: every solder joint clean and bright, no cold joints, no whisker bridges.
- Lead-dress audit: no wires touching where they shouldn't, no signal wires running parallel to heater wires.
- Mechanical: all transformers and large components tightly mounted, no loose hardware on the chassis.
- Tube sockets: pins all clean, no debris or solder splash inside the socket.
- Smell test: any burnt smell? Stop and investigate.
- The "did I install the tubes?" question — generally power up *without* tubes first, then install once basic voltages are confirmed.
