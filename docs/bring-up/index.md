# Bring-up

After the amp is fully wired and visually inspected, **bring-up** is the procedural sequence for turning it on for the first time without damaging anything (including yourself).

!!! warning "Read first"
    Read [high-voltage safety](../test-equipment/high-voltage-safety.md) before any of this. After the first power-on, the [filter caps](../components/filter-capacitors.md) hold lethal charge for minutes to hours after power-off.

This section is **not yet written** — it gets produced once the amp is physically built and we go through the bring-up in practice. The page outlines below are scaffolds for what each page will cover.

- [Pre-power checklist](pre-power-checklist.md) — visual inspection, smell test, mechanical checks.
- [Continuity checks](continuity-checks.md) — every node verified with a meter before any power.
- [First power-on](first-power-on.md) — the slow [variac](../test-equipment/variac.md) ramp procedure.
- [Voltage checks](voltage-checks.md) — what to measure where, expected values.
- [Bias adjustment](bias-adjustment.md) — setting the four [EL34s](../components/el34-output-tube.md) using the [individual bias pots mod](../modifications/individual-bias-pots.md).
- [Functional testing](functional-testing.md) — signal injection, listening tests, square-wave testing.
